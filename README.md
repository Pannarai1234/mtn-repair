# ระบบแจ้งซ่อมเครื่องจักร (MTN)

เว็บแอปหน้าเดียวสำหรับแจ้งซ่อมและติดตามงานซ่อมเครื่องจักรในโรงงาน ใช้ได้ทั้งมือถือและคอมพิวเตอร์ ค่าเริ่มต้นเป็นธีมสว่างโทนฟ้าอ่อน กดปุ่มรูปดวงอาทิตย์เพื่อสลับเป็นธีมมืดหรือตามระบบ (แก้สีได้ที่ตัวแปรต้นไฟล์ `css/style.css`)

- **Frontend**: HTML/CSS/JS ล้วน (ไม่ต้อง build) โฮสต์บน GitHub Pages
- **Backend**: Cloudflare Worker (REST API) + Cloudflare D1
- **ช่วงทดสอบ**: ใช้ `localStorage` ได้เลยโดยไม่ต้องมี backend แล้วสลับไปใช้ API ด้วยการแก้ค่าเดียว

```
index.html            หน้าเว็บ (ทุกหน้าจออยู่ในไฟล์นี้)
css/style.css         สไตล์ + dark mode + responsive
js/config.js          ค่าตั้งต้น: โหมด local/api, URL ของ API, ความถี่ polling
js/layout-data.js     ผังโรงงาน: ผนัง โซน รหัสและตำแหน่งเครื่อง (ถอดจากแบบแปลน)
js/auth.js            จุดต่อระบบล็อกอิน (ตอนนี้เลือกบทบาทได้เลย)
js/store.js           data layer: LocalStore (localStorage) และ ApiStore (fetch) ใช้ interface เดียวกัน
js/sound.js           เสียงเตือน (Web Audio API ไม่ต้องมีไฟล์เสียง)
js/map.js             วาดผังแบบ SVG (ซูม/เลื่อน/แตะ) และโหมดแก้ไข (ลากย้าย ปรับขนาด)
js/app.js             ตัวควบคุมหน้าจอทั้งหมด
worker/src/index.js   Cloudflare Worker REST API
worker/schema.sql     โครงสร้างตาราง D1
worker/seed.sql       โซนและเครื่องจักรทั้งหมดตามผัง (สร้างอัตโนมัติ)
tools/build-seed.mjs  สร้าง worker/seed.sql จาก js/layout-data.js
worker/wrangler.toml  ค่าตั้ง Worker + D1
```

## ผู้ใช้ 3 บทบาท

| บทบาท | ทำอะไรได้ | หน้าแรก |
|---|---|---|
| 👷 พนักงาน | แจ้งซ่อม, ดูหน้าติดตามงาน (ปิดงานไม่ได้) | แจ้งซ่อม |
| 🔧 ช่าง | แจ้งซ่อม, ดูงานค้าง, บันทึกวิธีแก้และ **ปิดงาน** | ติดตามงาน |
| 🛠️ แอดมิน | ทุกอย่าง + ตั้งค่าแผนผังโรงงาน เครื่องจักร และแหล่งข้อมูล | ตั้งค่า |

## ผังโรงงาน

ถอดจากแบบ PLANT LAYOUT ฉบับ 02-Mar-2026: โรง 1 (264 เครื่อง), โรง 2 (152 เครื่อง), โรง 3 · 3.5 (47 เครื่อง) รวม 463 เครื่อง 58 โซน

- 🟢 เขียว = ปกติ หรือปิดงานแล้ว · 🔴 แดงกะพริบ = มีงานค้าง (เครื่องหยุดกะพริบเร็วกว่า มีป้ายรหัสชี้ตำแหน่ง)
- แท็บ "ทุกโรง" ดูภาพรวม แตะโรงเพื่อดูรายละเอียด แตะเครื่องเพื่อดูงานค้าง/ประวัติ/แจ้งซ่อม
- ซูม: ปุ่ม + −, ดับเบิลคลิก, Ctrl+ล้อเมาส์ หรือกางนิ้ว · ค้นรหัสเครื่องแล้วระบบซูมไปให้ · ปุ่ม ⛶ แสดงเต็มจอ
- **94 เครื่องติดป้าย "รอตรวจรหัส"** เพราะตัวอักษรในแบบไม่ชัดหรือไม่มีรหัสในแบบ แก้/ยืนยันได้ที่หน้า "ตั้งค่า" (เส้นประส้มบนผัง)
- รหัสเครื่องห้ามซ้ำ (ไม่สนตัวเล็ก/ใหญ่ เว้นวรรค ขีด จุด #) เพื่อใช้จับคู่กับ Google Sheet ภายหลัง

แก้รหัส ตำแหน่ง ขนาด โซน ได้ที่หน้า "ตั้งค่า" ส่วนผนัง/ห้องแก้ใน `js/layout-data.js`

## ลองใช้งานทันที (โหมดทดสอบ)

เปิด `index.html` ด้วยเว็บเซิร์ฟเวอร์ใดก็ได้ เช่น

```powershell
python -m http.server 8080
```

แล้วเปิด <http://localhost:8080> ครั้งแรกระบบจะโหลดผังโรงงานให้อัตโนมัติ ถ้าอยากดูเครื่องเสียบนผัง: แอดมิน → ตั้งค่า → "จำลองเครื่องเสีย 3 เครื่อง"

**ทดลองการแจ้งเตือน:** เปิด 2 แท็บ แท็บแรกเข้าเป็น "ช่าง" (หน้าติดตามงาน) แท็บที่สองเข้าเป็น "พนักงาน" แล้วแจ้งซ่อม
แท็บช่างจะมีเสียงเตือน เครื่องและโซนบนผังกะพริบแดง และขึ้นตัวเลขงานค้างทันที ถ้าเลือก "หยุดทำงาน" เสียงจะเป็นไซเรนและกะพริบเร็วกว่า

> ในโหมดทดสอบ ข้อมูลอยู่ในเบราว์เซอร์เครื่องนั้นเท่านั้น (คนละเครื่องไม่เห็นกัน) แอดมินล้างงานแจ้งซ่อมหรือโหลดผังจากแบบใหม่ได้ที่หน้า "ตั้งค่า"

## ติดตั้งใช้งานจริง

### 1) Cloudflare D1 + Worker

ต้องมีบัญชี Cloudflare และ Node.js 18 ขึ้นไป

```powershell
cd worker
npm install
npx wrangler login
npx wrangler d1 create mtn-repair
```

คัดลอก `database_id` ที่ได้ไปใส่ใน `worker/wrangler.toml` แล้วสร้างตาราง

```powershell
npm run db:init
```

แล้วโหลดโซนและเครื่องจักรตามผัง: `npm run db:seed` (รันครั้งเดียวบนฐานข้อมูลว่าง) ถ้าแก้ `js/layout-data.js` ให้รัน `node tools/build-seed.mjs` ที่โฟลเดอร์หลักก่อน

แก้ `ALLOWED_ORIGIN` ใน `wrangler.toml` เป็นโดเมน GitHub Pages ของคุณ เช่น `https://yourname.github.io` แล้ว deploy

```powershell
npm run deploy
```

จะได้ URL ประมาณ `https://mtn-repair-api.<subdomain>.workers.dev` เปิด `/health` ดูได้ว่าเชื่อมต่อ D1 และมีตารางครบ

ทดสอบ Worker บนเครื่องตัวเองก่อนได้ด้วย `npm run db:init:local` แล้ว `npm run dev`

### 2) ตั้งค่าหน้าเว็บให้เรียก API

แก้ `js/config.js`

```js
MODE: 'api',
API_BASE: 'https://mtn-repair-api.<subdomain>.workers.dev',
```

หรือทดลองก่อนโดยไม่ต้องแก้ไฟล์: เข้าเป็นแอดมิน → ตั้งค่า → แหล่งข้อมูล → เลือก Cloudflare API ใส่ URL → "ทดสอบการเชื่อมต่อ" → "บันทึกและใช้งาน" (มีผลเฉพาะเบราว์เซอร์นั้น)

### 3) GitHub Pages

push ทั้งโฟลเดอร์ (ไม่จำเป็นต้องมีโฟลเดอร์ `worker/` แต่ใส่ไว้ได้) ขึ้น GitHub แล้วไปที่ Settings → Pages → Deploy from a branch → เลือก branch `main` / root

## API

ทุก endpoint รับ/ส่ง JSON และใช้ prefix `/api` ได้ด้วย (เช่น `/api/jobs`)

| Method | Path | หน้าที่ |
|---|---|---|
| GET | `/health` | สถานะ API และตารางใน D1 |
| GET / POST | `/zones` | รายการโซน / เพิ่มโซน `{name, plant, x, y, w, h}` |
| GET / PUT / DELETE | `/zones/:id` | ดู / แก้ / ลบโซน (เครื่องในโซนจะกลายเป็น "ไม่ระบุโซน") |
| GET / POST | `/machines` | รายการเครื่อง / เพิ่มเครื่อง `{name, detail, plant, zone_id, x, y, w, h, shape, verify}` (รหัสซ้ำ → 409) |
| GET / PUT / DELETE | `/machines/:id` | ดู / แก้ / ลบเครื่อง (ลบไม่ได้ถ้ายังมีงานค้าง → 409) |
| GET | `/jobs` | รายการงาน (ดูด้านล่าง) |
| POST | `/jobs` | แจ้งซ่อม `{machine_id, problem, impact, stopped, reported_by}` |
| GET | `/jobs/:id` | ดูงาน |
| PUT | `/jobs/:id/close` | ปิดงาน `{note, closed_by}` (ปิดซ้ำ → 409) |

`GET /jobs` รับ query ได้ 3 แบบ

- ไม่ระบุ — งานค้างทั้งหมด + งานล่าสุด `limit` รายการ (ค่าเริ่มต้น 300)
- `?status=open` หรือ `?status=closed&limit=100`
- `?since=2026-11-19T07:00:00.000Z` — เฉพาะงานที่เปลี่ยนแปลงหลังเวลานั้น

ทุกครั้งจะส่ง header `X-Total-Count` = จำนวนงานทั้งหมด ข้อผิดพลาดตอบเป็น `{ "error": "ข้อความภาษาไทย" }`

### ฐานข้อมูล

ตามที่กำหนด (`zones`, `machines`, `jobs`) และเพิ่มคอลัมน์

- `zones.plant` และ `machines.plant, detail, x, y, w, h, shape, verify` — ตำแหน่งบนผังและรายละเอียดเครื่อง

- `reported_by`, `closed_by` — ชื่อผู้แจ้งและผู้ปิดงาน (เตรียมไว้สำหรับระบบล็อกอิน)
- `updated_at` — ให้หน้าเว็บ polling แบบดึงเฉพาะงานที่เปลี่ยน (`?since=`) แทนการโหลดทั้งตารางทุก 5 วินาที

## การอัปเดตอัตโนมัติและค่าใช้จ่าย

- หน้าเว็บดึงงานทุก 5 วินาที (`POLL_MS`) และดึงโซน/เครื่องจักรทุก 5 นาที (`META_POLL_MS`) เพราะมีหลายร้อยแถวและเปลี่ยนไม่บ่อย — ถ้าแอดมินแก้ผัง จออื่นจะเห็นภายใน 5 นาที หรือรีเฟรชหน้า
- รอบแรกโหลดงานค้างทั้งหมด + งานล่าสุด 300 งาน รอบต่อไปขอเฉพาะงานที่เปลี่ยน และโหลดใหม่ทั้งหมดทุก 10 นาที
- 1 หน้าจอที่เปิดทิ้งไว้ตลอด 24 ชม. ≈ 18,000 requests/วัน
  Workers แผนฟรีได้ 100,000 requests/วัน → ใช้พร้อมกันได้ราว 5 หน้าจอตลอดวัน
  ถ้ามีจอมากกว่านั้น ให้เพิ่ม `POLL_MS` (เช่น 10000) หรือใช้แผน Workers Paid

## เสียงเตือน

เบราว์เซอร์ไม่ยอมให้เว็บเล่นเสียงจนกว่าผู้ใช้จะแตะหน้าจอ 1 ครั้ง ถ้าเปิดหน้าใหม่แล้วยังไม่ได้แตะ จะมีแถบสีเหลือง "แตะเพื่อเปิดเสียงเตือน"
สำหรับจอที่เปิดทิ้งไว้ (เช่น จอในห้องช่าง) ให้แตะหน้าจอหนึ่งครั้งหลังเปิดเบราว์เซอร์ ปุ่ม 🔔 มุมขวาบนใช้เปิด/ปิดเสียง

## ต่อระบบล็อกอินในอนาคต

- **หน้าเว็บ**: แก้ `Auth.login()` ใน `js/auth.js` ให้เรียก `POST /auth/login` แล้วเก็บ token ไว้ใน session
  `ApiStore` จะแนบ `Authorization: Bearer <token>` ให้ทุกคำขอเอง และถ้า API ตอบ 401 จะเด้งกลับหน้าเข้าสู่ระบบ
- **Worker**: ตั้ง `AUTH_MODE = "jwt"` แล้วเขียน `verifyToken()` ใน `worker/src/index.js`
  ทุก endpoint เช็กสิทธิ์ผ่าน `requirePerm()` ไว้แล้ว (ตาราง `PERMS` ต้องตรงกับ `ROLES` ใน `js/auth.js`)
- เมื่อเปิดใช้ ชื่อผู้แจ้ง/ผู้ปิดงานจะมาจาก token แทนค่าที่หน้าเว็บส่งมา
